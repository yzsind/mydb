# XML Functions

| Function | Description |
| --- | --- |
| [`EXTRACTVALUE`](extractvalue.md) | Extracts matching direct child text or a scalar XPath value. |
| [`UPDATEXML`](updatexml.md) | Replaces exactly one selected XML node. |

See [XML functions](../../xml-functions.md) for the MySQL XPath dialect, variables,
collations, malformed-fragment warnings and unsupported constructs. These functions
operate on XML fragments; they do not load external entities or provide a general
XPath 1.0 runtime.
