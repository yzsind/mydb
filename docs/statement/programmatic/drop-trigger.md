# `DROP TRIGGER`

## Description

Drops a named trigger.

## Syntax

```ebnf
<drop-trigger> ::= 'DROP TRIGGER' [ 'IF EXISTS' ] <qualified-name>
```

## Behavior and Limitations

- IF EXISTS controls the missing-object diagnostic.
- The drop affects only subsequent DML and does not modify rows already written.

## Context, Errors, and Lifecycle

Requires TRIGGER on the subject table, resolved after finding the named trigger, and implicitly commits preceding DML. Metadata locking coordinates with active DML/trigger execution before publication. IF EXISTS controls only the missing-definition diagnostic. It does not remove audit/business rows generated by earlier trigger executions.

## Examples

```sql
DROP TRIGGER IF EXISTS orders_bi;
```
